# 割り箸カードゲーム v140

## 充電関連バグ修正

1. 充電Lv.5～9で「空間切断」を使用し、代償の手を選んだ際に進行不能になる不具合を修正。原因は未定義の `clearHandAttachments()` 呼び出しでした。既存の `clearBrokenTraps()` に統一しています。
2. 「予告状」で「過充電」を予約すると、その発動ターンに反動まで処理されてしまう不具合を修正。ターン開始時点ですでに予約済みだった反動だけをそのターンに適用し、予告状で新たに予約された反動は次の自分ターンまで保持します。
3. 「廉価バッテリー」の劣化回数がゲームリセット後も残る不具合を修正。
4. 疲労で「充電」を捨てないよう修正。充電しか手札にない場合は手札0枚として扱い、生存している手をランダムに1本減らします。
5. 「充電効果以外では捨てたり移動できない」という既存仕様に合わせ、通常のランダム手札破棄でも充電を保護するよう統一しました。

大会告知の起動時優先度は変更していません。
