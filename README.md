# 割り箸カードゲーム v141

## 不変の呪縛 修正

- 「不変の呪縛」を、付与された手の通常攻撃に対するカード由来の本数増加をすべて無効化する仕様へ統一。
- 雷撃、シナプス運動、空間切断、放電の加護など充電系の攻撃増加も無効化。
- 力の加護、捨て身、魔法少女系、共鳴強化、均衡の刃、決闘高潮など既存の攻撃増加も引き続き無効。
- ゴールドラッシュは通常の手の本数を上回る増加分のみ無効。下がる場合はそのまま適用。
- 悪党の印や天秤の加護など、通常攻撃へ後から加わる+1も無効。ドロー等の本数増加以外の付随効果は残る。
- 攻撃力を下げる効果・受ける本数を減らす効果は通常どおり適用。
- レーザービーム、エレクトリック、等価なる断罪など、カード自身が直接本数を加える効果には影響しない。
